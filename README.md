# 🍁 2026 北九州「首四日自駕＋博多定點」秋楓溫泉之旅 8天7夜

本行程專為 **4位大人、3位小孩 (共7人)** 的家庭設計，時間為 **2026年11月7日（週六）至 11月14日（週六）**。

為了讓旅程兼顧「下飛機直奔溫泉區輕鬆玩」、「免搬行李擠火車」以及「定點定居不頻繁換飯店」的最佳體驗，本行程採用 **「首 4 天福岡機場取還車自駕 ＋ 後 4 天博多定點電車新幹線」** 的最佳黃金組合：

1. **下飛機直奔別府/由布院 (Day 1~4 自駕)**：福岡機場通關後直接取 8 人座 MPV，一路開往太宰府、由布院金鱗湖與別府溫泉飯店。連住 3 晚別府/由布院溫泉渡假飯店，不頻繁換飯店。
2. **別府/九重夢山區自駕彈性**：暢玩【九州自然野生動物園】（叢林巴士餵獅子）、【九重夢大吊橋】360度滿山紅葉與【別府海地獄】。
3. **Day 4 走訪柳川順利回福岡還車**：開車回程走訪水鄉柳川體驗木舟與蒸籠鰻魚飯，開回福岡市區還車並入住博多飯店。
4. **博多定點連住 4 晚 (Day 4~8)**：後 4 天定居博多，安排九州新幹線熊本一日遊、海之中道海濱公園、LaLaport 實體鋼彈與天神地下街購物。

## 💡 行程亮點與親子貼心規劃

1. **下飛機直接開車**：Day 1-4 直接在福岡機場取車開往別府，省去推大行李擠地鐵/火車的疲勞。
2. **溫泉飯店連住 3 晚**：前 3 晚連續入住別府/由布院溫泉飯店（如杉乃井飯店），大人享受露天風呂棚湯與一泊二食，小孩暢玩溫泉水樂園。
3. **博多飯店連住 4 晚**：後 4 晚定居博多車站附近，不需頻繁打包收拾行李。
4. **安全座椅與駕照**：預約 8 人座車輛並配備 3 張兒童安全座椅，隨身攜帶台灣駕照正本與最新日文譯本。
