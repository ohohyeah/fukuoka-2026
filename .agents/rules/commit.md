# Git Commit 訊息規範 (Git Commit Message Rules)

當在 Antigravity 中生成 Git Commit 訊息時（包含點擊 Source Control / Git 面板的「生成 Commit 訊息 (AI Generate Commit Message)」按鈕或透過 Agent 產生）：

1. **語言與格式**：
   - 必須使用**繁體中文單行摘要**。
   - 不使用 Conventional Commits 前綴（不需加 `docs:`、`feat:` 等）。

2. **內容分析原則**：
   - 忽略純粹的排版調整、換行增減或格式微調。
   - 著重於實質內容的異動摘要，例如：
     - 行程安排、景點、地點、時間調整
     - 機票、住宿、租車、交通訂位細節更新
     - 預算金額、分攤細項變更
     - 行李清單項目增減
   - 以動詞開頭，簡明精準，字數控制在 50 字以內。
