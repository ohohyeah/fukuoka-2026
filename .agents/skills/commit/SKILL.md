# Commit 訊息生成 Skill (繁體中文 / 文件專案)

本 Skill 用於針對非程式碼（如 Markdown 文件、行程規劃、文字記錄）的變更，進行內容語意分析並提供高品質的繁體中文 Commit 訊息建議。

## 執行步驟

1. **檢查 Git 異動狀況**：
   - 執行 `git status` 與 `git diff`（包含已暫存 `git diff --staged` 與未暫存 `git diff`）檢查所有新增、修改或刪除的文件內容。

2. **分析內容實質變更**：
   - 忽略純粹的格式微調、空行增減或換行排版。
   - 著重於實質內容異動，例如：
     - 行程安排、時間、地點、景點變動
     - 機票、住宿、租車、交通訂位資訊更新
     - 預算金額、分攤細項、費用計算變更
     - 行李清單、攜帶物品增減
   - 將異動內容歸納為一開頭包含動作動詞的精準**繁體中文單行摘要**（長度控制在 50 字以內）。

3. **輸出建議與 Commit 指令**：
   - 簡述檢測到的文件異動要點。
   - 輸出建議的 Commit 訊息與可直接執行的指令範例，例如：
     ```bash
     git commit -m "更新第三天太宰府與天神購物行程細節"
     ```
   - **注意**：本 Skill 不會自動執行 `git commit` 指令，僅輸出生成之建議訊息供使用者審核及使用。
