# 景點行程規劃與導航交通估算 Skill (日本旅遊專用)

本 Skill 用於處理、規劃與美化旅遊行程 Markdown 文件（如 `03-每日詳細行程.md`），確保每個景點皆有精確的 **Google 地圖導航連結** 與 **交通時間估算**，並維護自駕與大眾運輸所需的全方位資訊。

---

## 核心執行原則與標準流程

當使用者要求新增景點、安排行程、更新或格式化每日行程表時，請遵循以下步驟：

### 1. 景點名稱與基本導航資訊補齊
- **中日文對照**：每個景點必須提供中文名稱與日文原名對照（如 `太宰府天滿宮 <br> 太宰府天満宮`）。
- **地址與聯絡資訊**：提供完整日本地址、電話號碼 (☎️)。
- **自駕 MapCode**：若為自駕行程或租車專案，必須查詢並附上 MapCode (📌)。

### 2. Google 地圖導航連結格式
- 表格中必須包含獨立的 `導航連結` 欄位。
- 導航連結格式統一使用 URL Encode 的搜尋語法：
  `[Google 地圖](https://maps.google.com/?q=SEARCH_QUERY)`
  - `SEARCH_QUERY` 優先使用英文或日文關鍵字（例如 `Dazaifu+Tenmangu` 或 `太宰府天満宮`），避免字元編碼錯誤。

### 3. 交通時間估算與緩衝機制
- **時間與項目欄位標註**：
  - 使用正確交通工具圖示標記行程切換：
    - 🚗 **自駕**：標明高速公路/一般道路估算車程，並加入 15–30 分鐘尋找停車場、塞車預留或休息站 (SA/PA) 緩衝時間。
    - 🚄 **新幹線 / 特急列車**：標明起訖站、列車名稱與班次估算搭乘時間。
    - 🚃 **JR / 市營地鐵 / 路面電車**：標明路線名稱與轉乘估算時間。
    - 🚌 **公車 / 巴士**：標明搭乘時間與等車預留。
    - 🚶 **步行**：標明步行時間（親子團步調建議加上 1.2~1.5 倍緩衝）。
- **親子/團體時間彈性**：預留景點停留、整理行李、推嬰兒車或廁所/餵奶的時間點。

### 4. 親子團下午午睡與彈性調配原則
- **13:00 – 16:00 下午午睡時段評估**：
  - **長途自駕時段**：優先利用下午拉車時段（如國道/高速公路行駛）讓幼童在車上安穩午睡。
  - **定點/飯店時段**：若無長途拉車，安排飯店 Check-in 房間休息，或選擇適合嬰幼兒推車之靜態/室內景點（如商場、公園休息區、咖啡廳）。
- **說明欄彈性備案標記**：
  - 在行程表格的「行程項目與活動內容」欄位中，補上午睡彈性備案（例如：標註車上下午睡、提早 Check-in 入住備案或靜態休息區備案），以便家長視當天小孩情緒隨時調整。

## 檢查清單 (Checklist)

在生成或修改行程前，確認已落實以下五大要素：
- [ ] 景點名稱是否包含日文名稱？
- [ ] 是否有獨立欄位且提供有效的 `[Google 地圖](https://maps.google.com/?q=...)` 連結？
- [ ] 行程時間與說明中是否明確註明交通方式、估算時間與緩衝時間？
- [ ] 日本自駕導航三要素（地址、電話 ☎️、MapCode 📌）是否完整記載？
- [ ] 13:00–16:00 下午時段是否已考慮小孩午睡需求，並於說明欄附上彈性應對備案（如車上午睡、飯店 Check-in 休息或推車備案）？
