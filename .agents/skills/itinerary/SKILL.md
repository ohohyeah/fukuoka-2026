# 景點行程規劃與導航交通估算 Skill (日本旅遊專用)

本 Skill 用於處理、規劃與美化旅遊行程 Markdown 文件（如 `03-每日詳細行程.md`），確保每個景點皆經過 **即時營運存續核實**，並具備精確的 **Google 地圖導航連結** 與 **交通時間估算**，維護自駕與大眾運輸所需的全方位資訊。

---

## 核心執行原則與標準流程

當使用者要求新增景點、安排行程、更新或格式化每日行程表時，請遵循以下步驟：

### 1. 景點存續性與營運狀態即時核實 (Spot Verification)
在將景點排入行程或更新資料前，**必須優先執行存續性與營業狀態查核**：
- **核實範圍**：
  - **永久歇業**：確認該景點、設施或店鋪未出現「閉業」、「閉店」、「閉館」或「廢業」。
  - **臨時休業 / 整修休館**：確認近期未因設施改裝、設備點檢、耐震工程等長期暫停開放。
  - **搬遷移轉**：確認是否有移轉新址、改名或由其他設施接手。
  - **定休日與季節公休**：比對行程預定出發當日（星期幾/日期），確認非每週固定公休日（定休日）、年末年始或冬季閉園。
- **搜尋查證策略與來源標準**：
  - **日文關鍵字檢索**：以景點日文原名搭配關鍵字檢索最新動態：
    `"[景點日文名]" (閉業 OR 閉店 OR 閉館 OR 移転 OR "臨時休業")`
  - **官方管道優先**：優先查閱景點官方網站（公式HP）之「お知らせ」、「新着情報」、「休館カレンダー（休館日曆）」及營業時間公告。
  - **多方即時輔佐**：檢視 Google 地圖營業標籤（確認無「永久停業」或「暫時關閉」）、Tabelog 營運狀態（餐飲設施適用）及地方觀光協會官網資訊。
- **異常應變與替代備案機制 (Fallback & Alternatives)**：
  - 若核實發現景點已永久歇業、長期休館或剛好適逢公休日，**不得直接排入有效行程**。
  - **主動警示**：在回應中清楚標註該景點異常狀況（例如：已於 202X 年閉店、目前整修至何時、當天適逢週三定休日等）。
  - **提供替代方案**：主動提供 **1～2 個性質相似、地理位置順路（車程 15～30 分鐘以內）** 的備選景點供使用者挑選替換。

### 2. 景點名稱與基本導航資訊補齊
- **中日文對照**：每個景點必須提供中文名稱與日文原名對照（如 `太宰府天滿宮 <br> 太宰府天満宮`）。
- **地址與聯絡資訊**：提供完整日本地址、電話號碼 (☎️)。
- **自駕 MapCode**：若為自駕行程或租車專案，必須查詢並附上 MapCode (📌)。

### 3. Google 地圖精確地標導航連結與實機核實規範 (Google Maps POI Landmark Verification)
- **非目的地不硬放連結（純過程免放）**：
  - 若行程項目僅為「車程移動、山路行駛、搭乘接駁車、純手續流程」等移動過程或過渡，**嚴格禁止硬加導航連結**。
  - 此類項目在表格的 `導航連結` 欄位應直接**留空**或填寫短橫線「`—`」（明確標註無需導航），避免干擾主要目的地導航。
- **地標精確性與絕對禁止經緯度 (Strict POI - No Raw Coordinates)**：
  - 目的地連結點開後，必須在 Google 地圖上**確實顯示實體地標資訊卡（POI Place Card）**，讓使用者一鍵看清店家/景點詳情並啟動導航。
  - **嚴格禁止使用純經緯度座標**（例如 `https://maps.google.com/?q=33.123,131.456`），避免使用者點擊後僅看見地圖中央的無名圖釘或無法識別店名/設施。
  - **特定設施精確導航**：若為特定停車場或出入口（如「九重“夢”大吊橋 中村側第 1 停車場」），應直接定位至該停車場專屬地標。
  - **無獨立地標卡之設施**：若為私人包棟民宿等無獨立 POI 卡片之場所，應使用「完整正規日文地址」進行搜尋定位（讓地圖精準標定門牌位置），或定位至最近的實體公共地標。
- **核准之連結 URL 格式**：
  - **格式 A（精確地標搜尋）**：使用 URL Encode 的地標檢索語法：
    `[Google 地圖](https://www.google.com/maps/search/?api=1&query=SEARCH_QUERY)` 或 `[Google 地圖](https://maps.google.com/?q=SEARCH_QUERY)`
    （`SEARCH_QUERY` 優先採用日文官方精確地標名＋所在區域，例如 `太宰府天満宮` 或 `山田サービスエリア+下り`，避免同名歧義）。
  - **格式 B（官方地標分享短網址）**：經瀏覽器實機查核後取得之官方分享短連結：
    `[Google 地圖](https://maps.app.goo.gl/XXXXX)`
- **瀏覽器實機查核機制 (Browser Verification Workflow)**：
  - **實機查核時機**：
    1. 遇到同名景點、連鎖分店或容易產生搜尋歧義的地點（例如同名拉麵店、多個地獄溫泉）。
    2. 私房景點、包棟 Airbnb 民宿、特定專屬停車場（如中村側 vs 北方側）、特定步道或景觀台。
    3. 不確定搜尋字串點開後是否真能開出正確實體地標卡（POI）時。
  - **查核流程**：
    - 啟動瀏覽器（Browser Tool / Subagent）前往 Google Maps 實際搜尋該景點名稱或地址。
    - 驗證畫面是否成功彈出專屬「實體地標資訊卡（Place Card）」（包含評分、相片、日文名稱、營業狀態）。
    - 確認無誤後，可直接採用該精確地標關鍵字或取得官方分享連結填入行程。

### 4. 交通時間估算與緩衝機制
- **時間與項目欄位標註**：
  - 使用正確交通工具圖示標記行程切換：
    - 🚗 **自駕**：標明高速公路/一般道路估算車程，並加入 15–30 分鐘尋找停車場、塞車預留或休息站 (SA/PA) 緩衝時間。
    - 🚄 **新幹線 / 特急列車**：標明起訖站、列車名稱與班次估算搭乘時間。
    - 🚃 **JR / 市營地鐵 / 路面電車**：標明路線名稱與轉乘估算時間。
    - 🚌 **公車 / 巴士**：標明搭乘時間與等車預留。
    - 🚶 **步行**：標明步行時間（親子團步調建議加上 1.2~1.5 倍緩衝）。
- **親子/團體時間彈性**：預留景點停留、整理行李、推嬰兒車或廁所/餵奶的時間點。

### 5. 親子團下午午睡與彈性調配原則
- **13:00 – 16:00 下午午睡時段評估**：
  - **長途自駕時段**：優先利用下午拉車時段（如國道/高速公路行駛）讓幼童在車上安穩午睡。
  - **定點/飯店時段**：若無長途拉車，安排飯店 Check-in 房間休息，或選擇適合嬰幼兒推車之靜態/室內景點（如商場、公園休息區、咖啡廳）。
- **說明欄彈性備案標記**：
  - 在行程表格的「行程項目與活動內容」欄位中，補上午睡彈性備案（例如：標註車上下午睡、提早 Check-in 入住備案或靜態休息區備案），以便家長視當天小孩情緒隨時調整。

## 檢查清單 (Checklist)

在生成或修改行程前，確認已落實以下六大要素：
- [ ] **景點存續與營運狀態**：是否已查證確認景點/店家目前正常營運（無永久閉業、改裝休館、搬遷或當日定休日問題）？若有異常是否已提供警示與替代備案？
- [ ] **中日文名稱**：景點名稱是否包含日文原名？
- [ ] **精確實體地標導航連結（嚴禁純經緯度）**：
  - 目的地點開後是否在 Google 地圖上具有明確實體地標資訊卡（POI）？
  - 是否已排除純經緯度座標（如 `33.123, 131.456`）？
  - 遇到歧義名、民宿或專屬停車場時，是否已透過瀏覽器實機查核確認？
- [ ] **純過程不強加連結**：純車程移動、交通過程或無固定目的地之過渡項目，導航欄位是否保持留空或標記「—」？
- [ ] **交通與緩衝估算**：行程時間與說明中是否明確註明交通方式、估算時間與緩衝時間？
- [ ] **自駕導航三要素**：日本自駕導航三要素（地址、電話 ☎️、MapCode 📌）是否完整記載？
- [ ] **親子午睡彈性備案**：13:00–16:00 下午時段是否已考慮小孩午睡需求，並於說明欄附上彈性應對備案（如車上午睡、飯店 Check-in 休息或推車備案）？
